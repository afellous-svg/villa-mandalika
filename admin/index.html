Synchronisation Airbnb (lecture seule)

URL iCal de ton calendrier Airbnb (Calendrier → Disponibilité → Synchronisation → Exporter calendrier). Pour les autres plateformes, utilise les champs Booking / Agoda / Abritel ci-dessous.

⚠️ La sync directe échoue ?

Airbnb bloque parfois les requêtes navigateur (CORS). Solution simple :
1. Ouvre l'URL iCal dans ton navigateur — un fichier .ics est téléchargé
2. Glisse ce fichier dans la zone « Importer un fichier .ics » ci-dessus
3. La sync marche à coup sûr

Autres plateformes (Booking, Agoda, Abritel)

Si tu diffuses sur d'autres plateformes, colle leur URL iCal ici. Elles seront sync auto comme Airbnb (au démarrage + toutes les 15 min). Liens directs : Extranet Booking · YCS Agoda · Abritel

📤 Diffusion de ton calendrier vers les plateformes

Ton app publie automatiquement un calendrier iCal public contenant toutes tes réservations directes + Airbnb + Booking + etc. Tu colles ce même lien sur Airbnb, Booking, Agoda et Abritel pour que toutes les plateformes voient TES dates bloquées et évitent les doubles réservations.

⚙️ Configuration GitHub — colle ton token ici

1. Va sur github.com/settings/tokens
2. « Generate new token » → Fine-grained personal access token
3. Token name : airbnb-ical · Expiration : 1 an · Repository access : « Public Repositories (read-only) »
4. Permissions : Account permissions → Gists → Read and write
5. Copie le token (commence par github_pat_) et colle-le ci-dessous.
